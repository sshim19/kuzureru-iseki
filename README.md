# 崩れる遺跡の脱出

足場が崩れる前に、上へ登るゲームです。同じ日は、だれが遊んでも同じ配置になります。

## 遊び方

1. 「のぼる」を押して始めます。タイトルと終了画面で、操作を「長押し」か「スワイプ」から選べます。選んだ操作はこの端末に保存されます。
2. 長押しでは、画面の左か右を押したまま力をためて、はなすとその向きに跳べます。スワイプでは、跳びたい向きに指をはらいます。長くはらうほど、高く遠くまで跳べます。パソコンでは、どちらの操作でも左右の矢印キーを押した長さで跳べます。
3. 長く押す（またははらう）ほど、高く遠くまで跳べます。短くても、小さく跳べます。
4. 着地した足場は、力をためているあいだも崩れていきます。ひびが入ったり揺れたりしたら、すぐに跳んでください。
5. 画面の下へ落ちると終わりです。登った高さ（m）を競います。

最高記録と、その日の最高記録は、この端末に保存されます。

終了画面の X と LINE のボタンから、いまの高さをそれぞれの投稿画面で共有できます。

## 開き方

ビルドは不要です。フォルダをウェブサーバーで公開するか、手元では次のように開きます。

```bash
python3 -m http.server
```

ブラウザで `http://localhost:8000/` を開いてください。`file://` では動きません。
